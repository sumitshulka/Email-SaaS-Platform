---
name: Color-only UI changes
description: Preserve Mailflow UI structure when the user requests only color or accent updates.
---

When the user asks to change colors or make accents more visible, keep the existing layout, spacing, typography, and component structure unchanged; adjust only color values.

**Why:** The user clarified that a request to improve color accents was not permission to redesign the Getting started area.

**How to apply:** For color-focused UI requests in Mailflow, compare class structure before and after, and avoid changing breakpoints, dimensions, typography, or arrangement unless explicitly requested.

---
name: Contact list workflow
description: User expectation for assigning existing contacts to lists.
---

Users should be able to add existing workspace contacts to a list directly from the Contact Lists page, without leaving that page.

**Why:** The user asked to manage list membership in the context where lists are created and reviewed.

**How to apply:** Keep list membership actions available from each list’s management view; preserve contacts’ other list memberships when adding them to one list.
